# Game feel: more arcade moments in the app (later)

**Status:** an idea for after launch (Hillel, 2026-10-29: "in the future we should have more arcade
style 2x bonus popups in the game with the option to disable. We could make it much more game like in
some ways"). Nothing built yet. The arcade look itself is in progress (docs/arcade-app-plan.md, from
the frontend).

## The idea

- **Bonus pop-ups while you sing:** "2x", "Combo x5", "Perfect!", "Streak!" bursting near the lane when
  you earn them, in the arcade style, never covering the notes you're about to sing.
- **Multipliers that mean something:** a run of notes in tune doubles the points for a while; a whole
  phrase in tune is a bonus; tied into stars, XP and the part leaderboards honestly (a leaderboard's
  score never depends on a cosmetic setting).
- **More game moments:** level-up fanfares, a stage-clear screen for a unit, achievements, a daily
  bonus round, maybe a "boss" challenge at the end of a unit.
- **An off switch:** a "Game effects" setting (on by default, remembered), and reduced motion turns
  the animations off. A quiet mode for rehearsals and teachers.

## To decide when it's picked up

- Which moments earn a pop-up, and how often, so it stays fun and never nags.
- Sound effects (a coin, a chime) and their own switch.
- How it reads on a phone, and for screen readers (announce briefly, or not at all).
